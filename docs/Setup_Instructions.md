
# Setup Instructions

## JDK Version Used
- Java 24.0.2 (installed on 2025-07-15)
- Java(TM) SE Runtime Environment (build 24.0.2+12-54)
- Java HotSpot(TM) 64-Bit Server VM (build 24.0.2+12-54, mixed mode, sharing)

## Hello World Program

```java
import java.util.*;

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

### Run and Output
- Compile: `javac HelloWorld.java`
- Run: `java HelloWorld`
- Expected terminal output:

```
Hello World
```

## Explanation
- `import java.util.*;` imports utility packages if needed.
- `public class HelloWorld` defines the Java class.
- `public static void main(String[] args)` is the program entry point.
- `System.out.println("Hello World");` prints the message to the terminal.
